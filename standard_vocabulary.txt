Standard vocabulary (canonical values)

This file defines the canonical English strings that should be used in code and stored in DB fields.
Models rule: Python class names stay English; SQL table/column names stay Italian (as in `src/db/models.py` / `scripts/init_db.py`).


Stand
- `Stand.status` (Piazzola.Stato)
  - `Available`
  - `Reserved`
  - `Occupied`


Flights
- `Flight.status` (Viaggio.Stato)
  - `Unscheduled`    (created, not yet handled by scheduler)
  - `Scheduled`      (departure plane assigned)
  - `Ongoing`        (in progress / inbound created+linked)
  - `Landing`        (arrival stand reserved + plane linked to stand)
  - `StandReserved`  (a stand has been reserved for this flight)

- `Flight.tipo` (Viaggio.Tipo)
  - `Cargo`
  - `Passengers`

- Route category (used in generator logic; not currently stored in DB by default)
  - `National`
  - `European`
  - `International`


Airplanes
- `Airplane.status` (Aereo.Stato)
  - `Parked`
  - `Reserved`
  - `InFlight`

- `Airplane.type` (Aereo.Tipo)
  - `Cargo`
  - `Passengers`

- `Airplane.range` (Aereo.Raggio) and `Airport.distance` (Aeroporto.Distanza)
  - `Short`
  - `Medium`
  - `Long`


Vehicles
- Prefab / simulator payload type (Unity -> server)
  - `plane`
  - `vehicle`

- `Vehicle.status` (Veicolo.Stato)
  - `Available`


Graph / spline IDs (Unity / graph JSON / server)
- Landing splines / node links
  - `LongLanding`
  - `MediumLanding`
  - `ShortLanding`
- Departure spline / node link
  - `Departure`
- Parking stand IDs
  - `Parking1`
  - `Parking2`
  - `Parking3`
- Stand IDs
  - `O1`..`O5`, `P1`..`P3`, `C1`..`C3`


Legacy / deprecated (Italian forms to map away from)
- Stand statuses: `Libero`, `Riservato`, `Occupato`
- Vehicle status: `Disponibile`
- Flight/Airplane type: `Passeggero`, `Passeggeri`, `Merce`
- Range/distance: `Corto`, `Medio`, `Lungo`
- Graph IDs: `AtterraggioLungo`, `AtterraggioMedio`, `AtterraggioCorto`, `Decollo`, `Parcheggio1`, `Parcheggio2`, `Parcheggio3`
