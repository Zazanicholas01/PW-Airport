Simulator new prefab structure

    - self.prefabs
        - Original list of prefab payload dictionaries from Unity
    
    - self.prefab_by_name
        - Dictionary: prefab_name --> prefab payload dict
    
    - self.plane_names
        - Set per evitare inserimenti doppi dove già indicizzati
    
    - self.planes_by_type_range
        - Key is (type, range) example ("Cargo", "Long")
        - Value is a deque of prefab names that match
        - Match both type and range at once
    
    - self.planes_by_type / by_range
        - Fallbacks if type or range missing

Defaultdict(deque) --> Dictionary that auto-creates a value when a missing key is accessed
    - No KeyError

Deque --> Double-Ended Queue
    - Container optimized for adding/removing/rotating at either end
    - Round Robin Selection
    - name = q[0] picks next prefab name
    - rotate(-1) moves that name to the back to change next pick
    - Example:
        - List pop(0) && List Append

add_prefabs
    - Loops each element and calls add_prefab(prefab)

add_prefab(prefab)
    - Appends to self.prefabs
    - Reads prefab name
    - Stores on self.prefab_by_name for direct indexing
    - Checks Unity payload type
    - Deduplicates using self.plane_names
    - Uses mapping functions from utils
    - Inserts the name into 3 deques:
        - (type, range)
        - type fallback
        - range fallback

pick_plane_prefab
    - Inputs
        - Flight_Type (Cargo / Passengers)
        - Required_Range (Short / Medium / Long)
    
    - Search for matches on range & type
    - When queue found:
        - Take first as prefab name
        - Rotate the queue so next call picks another prefab
        - Return the name
