## `runtime_bus.py`

Read this file as the post-setup event processor. Transport has already decoded JSON and decided setup is complete. The runtime handler’s job is to validate event payloads, load the related domain rows, apply state transitions, and trigger any follow-up effects such as despawn commands or disembark timers.

## Bootstrap And Injected Dependencies

`RuntimeBusHandler` depends on more transport-owned collaborators than the setup handler:

- `bus` and `commands` for outbound Unity commands
- `clock`, `clock_lock`, and `clock_changed` for simulation-time sleeps
- `Session` for runtime DB transitions
- `append_event(...)` for backend event logging

That makes this file the bridge between inbound runtime events and the rest of the backend runtime.

<TransportCodeBlock title="runtime_bus.py">

def _default_sessionmaker() -> sessionmaker:

        self,
        prefab_store,
        session_factory: sessionmaker | None = None,
        *,
        bus = None,
        commands = None,
        clock=None,
        clock_lock: asyncio.Lock | None = None,

## Queue Consumer Boundary

The processing model stays the same as `setup_bus.py`: transport enqueues decoded payloads, the handler owns one consumer task, and state mutations happen in-order.

That avoids cross-event races between stand release, path completion, and timer startup.

<TransportCodeBlock title="runtime_bus.py">
```python
async def start(self):
    """Launch the background consumer task"""
    if self._task is None or self._task.done():
        self._task = asyncio.create_task(self._event_loop())

async def enqueue(self, payload: dict):
    """Entrypoint to push a payload into the async queue"""
    await self.queue.put(payload)

async def _event_loop(self):
    """Consume forever loop"""
    while True:
        payload = await self.queue.get()
        try:
            await self.handle_payload(payload)
        finally:
            self.queue.task_done()
```
</TransportCodeBlock>

## Event Routing And Runtime Dependencies

`handle_payload(...)` begins with a narrow filter:

- payload must be `type="event"`
- `airplane_id` must be a non-empty string
- stand lookup happens through SQLAlchemy before event-specific logic

From there the handler branches into `path_completed` and `plane_left_stand`.

<TransportCodeBlock title="runtime_bus.py">
```python
def _find_stand_id_by_airplane_id(self, session, airplane_id: str) -> str | None:
    """Helper DB Function to lookup at which stand currently references this airplane"""

    return session.execute(select(models.Stand.id).where(models.Stand.airplane_id == airplane_id)).scalar_one_or_none()

async def handle_payload(self, payload: dict):
    """Payload Handling event router"""

    if payload.get("type") != "event":
        return

    evt = payload.get("event")
    airplane_id = payload.get("airplane_id")
    if not isinstance(airplane_id, str) or not airplane_id:
        return

    with self.Session() as session:
        stand_id = self._find_stand_id_by_airplane_id(session, airplane_id)
```

## Departure Versus Landing Path Completion

The central dependency here is the database model graph. Runtime loads the airplane, then the current `Path`, then branches on `path.destination`.

If the route ends at `Departure`, runtime:

- advances airplane and flight state
- commits DB changes
- optionally sends a despawn command back to Unity through the injected bus proxy

If the route is not `Departure`, runtime instead enters landing completion flow.

<TransportCodeBlock title="runtime_bus.py">

## Plane Left Stand And Event Logging

The second runtime event is simpler but still dependency-driven. The handler resolves the stand through SQLAlchemy, validates that the stand still belongs to the reported airplane, then releases it and appends a backend event.

This is deliberately conservative: mismatches are logged and ignored.

## Simulation-Time Disembark Dependencies

The most transport-coupled part of `runtime_bus.py` is the disembark timer. It does not sleep in wall-clock time when a simulation clock is present.

Instead it depends on:

- `clock.now()` for the authoritative simulated time
- `clock.time_scale` for pause or fast-forward
- `clock_lock` for consistent reads
- `clock_changed` so scale changes can wake the timer loop early

This is what makes pause freeze disembark completion and time-scale changes accelerate or slow it correctly.

<TransportCodeBlock title="runtime_bus.py">
```python
def _start_disembark_timer(self, airplane_id: str) -> None:
    old = self._disembark_tasks.pop(airplane_id, None)
    if old is not None:
        old.cancel()

    self._disembark_tasks[airplane_id] = asyncio.create_task(self._finish_disembark(airplane_id))
```
</TransportCodeBlock>

<TransportCodeBlock title="runtime_bus.py">
```python
async def _sleep_sim_seconds(self, seconds: float) -> None:
    if seconds <= 0:
        return

    clock = self._clock
    if clock is None:
        await asyncio.sleep(seconds)
        return

    if self._clock_lock is None:
        target = clock.now() + timedelta(seconds=seconds)
    else:
        async with self._clock_lock:
            target = clock.now() + timedelta(seconds=seconds)

    while True:
        if self._clock_lock is None:
            now = clock.now()
            time_scale = float(getattr(clock, "time_scale", 1.0))
        else:
            async with self._clock_lock:
                now = clock.now()
                time_scale = float(getattr(clock, "time_scale", 1.0))

        remaining_sim_s = (target - now).total_seconds()
        if remaining_sim_s <= 0:
            return

        if (not math.isfinite(time_scale)) or time_scale <= 0.0:
            timeout = 1.0
        else:
            timeout = min(1.0, max(0.01, remaining_sim_s / time_scale))
```
</TransportCodeBlock>

async def _finish_disembark(self, airplane_id: str) -> None:
    try:
        await self._sleep_sim_seconds(self._disembark_sim_seconds)

        with self.Session() as session:
            airplane = session.get(models.Airplane, airplane_id)
            if airplane is None:
                return
            if getattr(airplane, "status", None) != AIRPLANE_STATUS.DISEMBARKING:
                return

            airplane.status = AIRPLANE_STATUS.PARKED

            flight = session.scalars(
                select(models.Flight)
                .where(models.Flight.airplane_id == airplane_id)
                .where(models.Flight.status.in_((FLIGHT_STATUS.DISEMBARKING, FLIGHT_STATUS.LANDING)))
                .order_by(models.Flight.arrival_time.desc())
            ).first()

            if flight is not None:
                flight.status = FLIGHT_STATUS.COMPLETED

            session.commit()

        append_event({
            "type": "backend_event",
            "event": "disembark_complete",
            "airplane_id": airplane_id,
        })
