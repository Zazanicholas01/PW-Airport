## `spawn_tracking.py`

Read this file as the persistence guarantee behind runtime spawns. It is deliberately small: given a prefab and an optional airplane id, it ensures there is a usable Airplane row in the database before later state transitions depend on it.

## Existing-Row Reuse

If the caller already provides an airplane id and the row exists, the function exits early. That keeps spawn tracking idempotent for already-persisted airplanes.

If no id is provided, a new UUID is generated up front.

<TransportCodeBlock title="spawn_tracking.py">
```python
        if airplane_id:
            existing = session.get(models.Airplane, airplane_id)

            if existing is not None:
                return airplane_id
        else:
            airplane_id = str(uuid4())
```

## Prefab Classification And Safe Fallback

The key business dependency here is `src.utils.mapping`. The service tries to classify the prefab into:

- airplane range
- airplane type

If mapping fails, it still proceeds with safe default values rather than aborting the spawn flow.

<TransportCodeBlock title="spawn_tracking.py">
```python
        try:
            range_value = range_for_airplane_model(prefab)
            airplane_type = type_for_airplane_model(prefab)
        except ValueError:
            logging.warning("Unknown prefab=%r; using defaults", prefab)

            range_value, airplane_type = "Medium", "Passengers"
```

## Airplane Row Creation

Once the id and classification are known, the service creates a baseline Airplane row with default operational values and commits it immediately.

That is the whole guarantee it provides: from this point on, later runtime layers can safely refer to that airplane id in the database.

<TransportCodeBlock title="spawn_tracking.py">
```python
        airplane = models.Airplane(
            id=airplane_id,
            type=airplane_type,
            range=range_value,
            model=prefab,
            capacity=100,
            status="Parked",
            speed=0.0,
            fuel_level=1.0,
            maintenance=False,
            airline_code=None,
            route_id=None,
        )

        session.add(airplane)
        session.commit()
        logging.info("[db] Airplane created id=%s prefab=%s", airplane_id, prefab)
        return airplane_id
```
