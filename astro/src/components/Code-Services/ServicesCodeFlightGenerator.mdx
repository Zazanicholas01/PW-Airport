## `flight_generator.py`

Read this file as the scenario-builder service for the simulation dataset. It does not dispatch commands or advance runtime state. Its job is to construct a coherent batch of Flight rows from DB metadata, compatibility rules, and randomized but window-aware time selection.

## Generator State And Dependencies

The service keeps only a small amount of state:

- the local airport ICAO
- a session factory
- an injectable RNG

Everything else is loaded or derived per generation run.

## Metadata Loading

`load_metadata(...)` is the first DB-facing step. It defines the pools the generator is allowed to use:

- remote airports only
- all terminals
- airlines restricted to the allowed codes

<TransportCodeBlock title="flight_generator.py">
```python
def load_metadata(self, session):
    """Prende la sessione DB e esegue le query"""

    airports = (
        session.query(models.Airport)
        .filter(models.Airport.icao != self.personal_airport)
        .all()
    )

    terminals = session.query(models.Terminal).all()

    airlines = (
        session.query(models.Airline)
        .filter(models.Airline.icao.in_(ALLOWED_AIRLINES))
        .all()
    )
    return airports, terminals, airlines
```

## Time Window Helpers

Two helper methods drive the temporal side of generation:

- `_times_departure_within_window(...)`
- `_times_arrival_within_window(...)`

They keep generated flights inside an active window while preserving a minimum and maximum travel duration.

<TransportCodeBlock title="flight_generator.py">
```python
def _times_departure_within_window(
    self,
    *,
    window: timedelta,
    min_duration: timedelta = timedelta(minutes=30),
    max_duration: timedelta = timedelta(minutes=240),
    guard: timedelta = timedelta(minutes=1),
) -> tuple[datetime, datetime]:
    now = self._utc_now()

    dep_lower = now + guard
    dep_upper = now + window - guard

    if dep_upper <= dep_lower:
        dep_time = dep_lower
    else:
        dep_time = self._random_time_between(dep_lower, dep_upper)

    duration_s = self.rng.randint(int(min_duration.total_seconds()), int(max_duration.total_seconds()))
    arr_time = dep_time + timedelta(seconds=duration_s)
    return dep_time, arr_time
```
</TransportCodeBlock>

## Compatibility And Flight Construction

The service builds each flight through several smaller rules:

- parked-airplane compatibility for the first forced departure
- route category from remote airport country
- airline selection from route category and flight type
- terminal selection by cargo or passenger preference
- ICAO-like code generation through per-airline counters

```python
def _route_category(self, remote_airport: models.Airport) -> str:
    country = (remote_airport.country or "").lower()

    if country == "italia":
        return AIRLINE_CATEGORIES.NATIONAL
    if country in EUROPEAN_COUNTRIES:
        return AIRLINE_CATEGORIES.EUROPEAN
```

## Scenario Regeneration Entry Point

`generate_flights(...)` is the public entrypoint. It:

1. deletes all current `Flight` rows
2. loads metadata
3. derives parked compatibility pairs
4. builds `n` new flights
5. commits the new scenario batch

<TransportCodeBlock title="flight_generator.py">
```python
def generate_flights(self, n: int, *, ensure_in_window: bool = True, window: timedelta = timedelta(hours=1)) -> list[models.Flight]:
    """Generazione effettiva dei viaggi random"""

    if n <= 0:
        return []

    flights: list[models.Flight] = []

    with self.Session() as session:
        session.execute(
            delete(models.Flight)
        )
        session.commit()

        airports, terminals, airlines = self.load_metadata(session)
```
