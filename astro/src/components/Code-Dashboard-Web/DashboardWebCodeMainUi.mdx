## Simulated Clock Projection

<TransportCodeBlock title="dashboard.js">
```javascript
function currentSimUnixMs() {
  if (!clockAnchor) return null;
  const elapsedRealMs = Date.now() - clockAnchor.receivedAtMs;
  return clockAnchor.simUnixMs + elapsedRealMs * clockAnchor.timeScale;
}
```
</TransportCodeBlock>

That projected clock drives both the visible time label and the per-flight delta-minute cells.
