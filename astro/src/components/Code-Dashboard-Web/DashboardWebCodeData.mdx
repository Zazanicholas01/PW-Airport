## Short-Lived Detail Cache

Detail pages refresh themselves every few seconds. The module avoids hammering the DB by caching snapshots for two seconds.

<TransportCodeBlock title="dashboard_data.py">
```python
DETAIL_CACHE_TTL_SECONDS = 2.0
FLIGHT_DETAIL_CACHE = {}
PLANE_DETAIL_CACHE = {}

def _cache_get(cache, key) -> dict[str, object] | None:
    cached = cache.get(key)
    if cached is None:
        return None
```

```python
def _read_flight_detail_snapshot(flight_id: str) -> dict[str, object]:
    with DASHBOARD_SESSION() as session:
```

## Event Log, Clock, And Main Snapshots

The module parses log lines and clock sync lines from `events.jsonl`, reconstructs simulated current time, and then builds two dashboard-wide snapshots:

- `read_window_flights_snapshot()`
- `read_planes_on_ground_snapshot()`

<TransportCodeBlock title="dashboard_data.py">
```python
def read_window_flights_snapshot() -> dict[str, object]:
    now_utc = _current_sim_now_utc()
    flights = list_flights_in_sliding_window(
        airport_icao=WINDOW_AIRPORT_ICAO,
        now_utc=now_utc,
        window=WINDOW_DURATION,
    )
```
