## Base And URL Construction

The file defines the shared declarative `Base` and then builds a connection URL. The important design point is the fallback sequence:

- use `DATABASE_URL` when present
- otherwise compose the URL from `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_HOST`, `POSTGRES_PORT`, and `POSTGRES_DB`

<TransportCodeBlock title="engine.py">
```python
Base = declarative_base()

def build_database_url() -> str:
    """Return the Postgres connection URL, preferring DATABASE_URL when set."""
    url = os.environ.get("DATABASE_URL")
    if url:
        return str(make_url(url))

    user = os.environ.get("POSTGRES_USER", "airport")
    password = os.environ.get("POSTGRES_PASSWORD", "airport")
    host = os.environ.get("POSTGRES_HOST", "localhost")
    port = os.environ.get("POSTGRES_PORT", "5433")
    db = os.environ.get("POSTGRES_DB", "Airport")

    return f"postgresql+psycopg://{user}:{password}@{host}:{port}/{db}"
```

## Cached Engine Factory

`get_engine()` is the real entry point consumed by the rest of the codebase. Because it is cached, repeated imports from schedulers, services, or scripts do not create a new engine every time.

<TransportCodeBlock title="engine.py">
```python
@lru_cache()
def get_engine():
    """Create (and cache) a SQLAlchemy engine."""
    return create_engine(build_database_url(), future=True, pool_pre_ping=True)
```
</TransportCodeBlock>

`pool_pre_ping=True` matters here because this app runs against a Dockerized Postgres service that can be restarted while the Python process is still alive.

## Session Yield Helper

This helper is deliberately tiny. It does not own transaction policy; it only standardizes open and close behavior when a caller already has a `Session` factory.

<TransportCodeBlock title="engine.py">
```python
def get_db(Session):
    db = Session()
    try:
        yield db
    finally:
        db.close()
```
