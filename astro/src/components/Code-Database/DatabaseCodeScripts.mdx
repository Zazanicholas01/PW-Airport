## Full Schema Reset

`init_db.py` is intentionally destructive. It is a local-development reset script, not a migration tool.

The key flow is:

1. connect to the admin database
2. terminate connections to the target DB
3. drop and recreate the target DB
4. run all `DROP TABLE`, `CREATE TABLE`, and `ALTER TABLE` statements

<TransportCodeBlock title="init_db.py">
```python
def recreate_database() -> None:
    """Drop and recreate the target database to ensure a clean state."""
    with psycopg.connect(
        dbname=ADMIN_DB,
        user=DB_USER,
        password=DB_PASSWORD,
        host=DB_HOST,
        port=DB_PORT,
        autocommit=True,
    ) as admin_connection:
        with admin_connection.cursor() as cursor:
            cursor.execute(
                """
                SELECT pg_terminate_backend(pid)
                FROM pg_stat_activity
                WHERE datname = %s
                  AND pid <> pg_backend_pid();
                """,
                (DB_NAME,),
            )
            cursor.execute(
                sql.SQL("DROP DATABASE IF EXISTS {}").format(sql.Identifier(DB_NAME))
            )
            cursor.execute(
                sql.SQL("CREATE DATABASE {}").format(sql.Identifier(DB_NAME))
            )
```

## Seed Data

`startup.py` provides the initial static records the rest of the app assumes exist:

- passengers and cargo terminals
- the local and remote airports with distance categories
- airlines
- stands
- parking spots
- vehicles

<TransportCodeBlock title="startup.py">
```python
def insert_seed_values() -> None:
    with Session() as session:
        if not _has_rows(session, models.Terminal):
            add_terminal(session)
        ...
        if not _has_rows(session, models.Vehicle):
            add_vehicles(session)
```
</TransportCodeBlock>

## Stands And Airport Metadata

Two seed blocks matter especially for runtime behavior:

- `evaluate_distance_airports()` decides the range category associated with each airport
- `add_stands()` creates the initial `O`, `C`, and `P` stand inventory used by reservation logic

<TransportCodeBlock title="startup.py">
```python
def categorize(distance_km):
    if distance_km is None:
        return None
    if distance_km < 500:
        return "Short"
    if distance_km < 4000:
        return "Medium"
    return "Long"
```
</TransportCodeBlock>
