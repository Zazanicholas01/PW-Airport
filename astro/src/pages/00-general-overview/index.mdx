## What “Setup” Means

> At runtime, Unity bootstraps the backend by sending the world-building inputs the scheduler needs before aircraft movement can be generated.

The setup phase sends:

- spline definitions, including a `MasterSpline`
- prefab catalog data used to map simulation assets

The backend converts that setup payload into persistent routing information and stores the resulting movement structures as `Path` and `Percorso` rows in the database.
