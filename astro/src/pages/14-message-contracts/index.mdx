# Message contracts and vocabulary

This topic consolidates the high-level contracts documented in `../../../README.md` and expands the canonical vocabulary into a dedicated file.

## Primary message types

### Unity -> Python

- Setup control: `setup-init`, `send-splines`, `finish-send-splines`, `send-prefabs`, `finish-send-prefabs`
- Spline payload: `{ "type":"event", "event":"spline", "spline": {...} }`
- Runtime events: `path_completed`, `plane_left_stand`
- Time commands: `set_time_scale`, `set_sim_time`

### Python -> Unity

- `welcome`
- `spawn_plane`
- `start_path` (ordered spline segments)
- `clock_sync`
