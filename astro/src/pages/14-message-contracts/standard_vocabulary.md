# Standard vocabulary

These values are used across code for statuses and type fields.

## Flight statuses

- `Unscheduled`
- `Scheduled`
- `Lan_Ongoing`
- `Landing`
- `Disembarking`
- `Completed`
- `StandReserved`

## Airplane statuses

- `Parked`
- `Reserved`
- `InFlight`
- `Disembarking`

## Stand statuses

- `Available`
- `Reserved`
- `Occupied`

## Flight types

- `Cargo`
- `Passengers`

## Range

- `Short`
- `Medium`
- `Long`
