# Operational Commands

This page lists the commands that match the current project setup.

## Backend

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Python backend locally:

```bash
python -m src.server
```

Notes:

- This is the main host-local runtime command.
- Unity connects to the backend over WebSocket, typically at `ws://localhost:8765`.

## Docs

Install Astro docs dependencies:

```bash
cd astro
bun install
```

Run the docs app directly:

```bash
cd astro
bun run dev
```

If the container stack is running, the docs are also available through nginx at:

```text
http://localhost:8001/docs/
```

## Docker Stack

Start the local stack:

```bash
docker compose up -d
```

Rebuild docs and nginx after docs or proxy changes:

```bash
docker compose up -d --build docs-site nginx
```

Inspect running services:

```bash
docker compose ps
```

Read logs:

```bash
docker compose logs docs-site nginx
```

Stop the stack:

```bash
docker compose down
```

## Database Utilities

Reset schema:

```bash
python scripts/init_db.py
```

Seed static data:

```bash
python scripts/startup.py
```

Connect interactively to the Postgres container shell:

```bash
docker compose exec postgres sh
```

Open a `psql` shell inside the Postgres container:

```bash
docker compose exec postgres psql -U airport -d Airport
```

## Typical Usage

Backend code changes:

```bash
python -m src.server
```

Docs changes:

```bash
cd astro
bun run dev
```

Integrated stack validation:

```bash
docker compose up -d
```
