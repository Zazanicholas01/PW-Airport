# Schedulers

This topic consolidates `../../schedulers/` behavior from `../../schedulers/README.md`.

## Spawn scheduler

File: `../../schedulers/spawn_scheduler.py`

Purpose:

- after setup completes, plan a clean bootstrap set of parked planes
- choose available stands + prefabs
- emit `spawn_plane` commands and ensure DB rows exist

## Flight scheduler (sliding window)

File: `../../schedulers/flight_scheduler.py`

Purpose:

- periodically query flights in a time window (`../../db/db_functions.py`)
- decide allocations and transitions for:
  - departures (assign airplane + path)
  - inbound preparation (ensure airplane for arrival)
  - arrivals (reserve stand + assign landing path)
