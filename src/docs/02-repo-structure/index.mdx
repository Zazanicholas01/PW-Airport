# Repository structure

## Top-level

- Python backend package: `../../`
- `../../../Unity_Scripts/`: Unity-side websocket + gameplay logic scripts
- `../../../scripts/`: DB reset/init + seed/bootstrap helpers
- `../../../docker-compose.yml`: local infra stack (Postgres, Metabase, init jobs)
- `../../../docker/initdb/`: container init SQL scripts
- `../../../data/`: runtime data (logs, etc.)
- `../../../schema_nodi.json`: node/link schema used by `../../init_graph.py`

## src map

- `../../server.py`: entrypoint (starts WebSocket server)
- `../../transport/`: websocket server + message bus + orchestration
- `../../handlers/`: setup/runtime event processing
- `../../schedulers/`: spawn + flight scheduling
- `../../db/`: SQLAlchemy models + DB helpers
- `../../domain/`: simulation clock + in-memory stores/snapshots
- `../../services/`: reusable services (flight generation, spawn tracking)
- `../../web/`: dashboard app + static UI
- `../../utils/`: mappings, event log helpers, small utilities
