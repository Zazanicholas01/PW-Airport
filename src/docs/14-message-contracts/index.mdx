# Message Contracts

This topic summarizes the contract boundary between Unity, the Python backend, and the browser dashboard.

## Main channels

- Unity -> Python transport payloads:
  - setup control events: `setup-init`, `send-splines`, `finish-send-splines`, `send-prefabs`, `finish-send-prefabs`
  - runtime events: `path_completed`, `plane_left_stand`
  - clock commands: `set_time_scale`, `set_sim_time`
- Python -> Unity commands:
  - `welcome`
  - `clock_sync`
  - `spawn_plane`
  - `start_path`
  - `despawn_plane`
- Python -> Dashboard payloads:
  - JSONL event-log records in `data/logs/events.jsonl`
  - FastAPI websocket payloads for events, clock, window flights, and planes on ground

## Example payloads

- Setup spline event:
  - `{ "type":"event", "event":"spline", "spline": {...} }`
- Runtime event:
  - `{ "type":"event", "event":"path_completed", "airplane_id":"..." }`
- Spawn command:
  - `{ "command":"spawn_plane", "prefab":"...", "stand_id":"...", "airplane_id":"..." }`
